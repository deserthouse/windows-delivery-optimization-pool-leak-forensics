# 使用范围声明 / Intended Use Statement

## 中文

- 本项目记录**在作者自己的设备上**对 Windows 传递优化引发内核内存泄漏的取证分析，目标读者是在**自己拥有并管理的设备上**排障的技术人员。
- 本文档与其中提及的工具仅供诊断与技术研究；处置步骤修改注册表与服务状态，**执行前请自行评估并创建还原点**。
- 作者与微软及任何硬件厂商**均无关联**；点名组件均为证据陈述，不做动机推断。
- 数据来自单台机器；不同版本行为可能不同。

本仓库的排查过程、证据整理与文稿撰写由 AI 深度参与完成；研究方向、关键决策与最终验收由人类作者负责。
